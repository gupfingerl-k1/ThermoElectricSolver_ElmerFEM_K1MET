# ThermoElectricSolver_ElmerFEM_K1MET
Compiled source code of segregated solver files for thermoelectric problems.

## Information
The available solver can be integrated into the ElmerFEM framework and allows to solve coupled thermoelectric problems on any domain. The solution procedure is a segregated approach and is therefore highly robust even with nonlinear material parameters.
For detailed information on how to use the compiled source code within the ElmerFEM framework contact lukas.gupfinger@k1-met.com
